# RealAirglow (working name)

A Kerbal Space Program 1.12 visual mod that renders Earth's nightglow (airglow) from cited
physics: the green 557.7 nm layer near 97 km, the red 630 nm layer near 250 km, OH, Na and
O₂ emission, viewed correctly from orbit and from the ground.

Status: **Phase 0 (research) done.** No renderer code yet.

- `docs/SPEC.md`: the project brief.
- `docs/PHYSICS.md`: every physical value, its source, and the changes against the brief.
- `reference/`: offline Python reference model (Phase 1); `reference/phase0/` holds the
  Phase 0 calculation scripts.
